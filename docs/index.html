🔧 Getting Started

Up and Running in Minutes

A one-time Windows installer uploads the utility directly to your Solo. After that, it lives permanently on the drone — no reinstallation needed, even after power cycles.

Download the Installer

Grab Solo Web Utility v1.2.0.exe — a single standalone Windows executable. No Python, Git, or dependencies needed on your PC.

Connect to SoloLink Wi-Fi

Power on your Solo and Controller, then connect your PC to the SoloLink Wi-Fi network as you normally would.

Run the Installer

Double-click Solo Web Utility v1.2.0.exe. It automatically connects via SSH, uploads all files, verifies syntax, and starts the web server on port 80.

Open Your Browser

Navigate to http://10.1.1.10 from any device connected to SoloLink. The utility is live and will persist across reboots permanently.

🏗️ Technical Design

Lives on Your Solo. Always Available.

The utility runs natively on the Solo Copter's onboard i.MX6 Linux companion computer — not on your phone or PC. It's always available at http://10.1.1.10 the instant you connect to SoloLink Wi-Fi.

On-Board Architecture

Written entirely in Python 2.7 for native compatibility with the Solo's embedded Linux environment. Zero external dependencies on the drone side.

  • Runs directly on the Solo's i.MX6 companion computer
  • Persists across power cycles via /etc/rc.local auto-start
  • Installed on /log/SoloWebUtility (6.5 GB persistent ext4 storage)
  • Web server on port 80 — accessible from any browser
  • MAVLink telemetry via UDP port 14560 through telem_forwarder
  • Direct Pixhawk parameter read/write with ACK verification
  • No internet connection required — fully self-contained
  • Works on any phone, tablet, laptop, or desktop with a browser
  • Compatible with all 3DR Solo Systems, any version
